Документация по сопровождению

v2.0.0 — HTTP→HTTPS

Стратегия сопровождения BMC_analyzer согласно ГОСТ 12207, ГОСТ Р 56920 и IEEE 829. Переход с незашифрованного HTTP (эпоха 2000-х) на защищённый протокол HTTPS.

Задание 1. Стратегия сопровождения (ГОСТ 12207, процесс 6.4)
1.1 Цель сопровождения

Обеспечить управление модификацией и перемещением программных продуктов (приложение BMC_analyzer и его контейнер) путём перехода с незашифрованного протокола HTTP на защищённый HTTPS на всех сайтах Компании 1.

1.4 Запрос на модификацию MR-2026-001

Идентификатор: MR-2026-001

Тип: Адаптивное сопровождение (Adaptive Maintenance)

Приоритет: Высокий (безопасность)

3.2 Аннотация изменений (для Руководства оператора)

Версия 2.0.0 от 03.05.2026

В связи с требованиями информационной безопасности система BMC_analyzer переведена на защищённый протокол HTTPS. При обращении по адресу http:// браузер автоматически перенаправляется на https:// (HTTP 301). Все страницы отдаются с заголовками безопасности: HSTS, CSP, X-Frame-Options, X-Content-Type-Options. Cookie сессии защищены флагами Secure и HttpOnly. Добавлена страница документации по сопровождению (/docs/) и API-эндпоинт проверки безопасности (/api/security-status/).

Задание 4. Модифицированный программный продукт (контейнер) — Dockerfile

Поскольку исходная виртуальная машина Linux (2000-е годы) уже не функционирует, сборка и развёртывание приложения выполняются через Docker-контейнер.

4.1 Dockerfile
FROM python:3.10-slim

LABEL maintainer="company2-dev@example.com"
LABEL version="2.0.0"
LABEL description="BMC_analyzer — переход HTTP→HTTPS (MR-2026-001)"

ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1 \
    DJANGO_SETTINGS_MODULE=django_project.settings \
    DEBUG=False

WORKDIR /app

# Системные зависимости
RUN apt-get update && apt-get install -y --no-install-recommends \
        gcc libpq-dev curl \
    && rm -rf /var/lib/apt/lists/*

# Python-зависимости
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Исходный код
COPY . .

# Статика и миграции
RUN python manage.py collectstatic --noinput
RUN python manage.py migrate --noinput

# Порт приложения
EXPOSE 3000

# Проверка работоспособности
HEALTHCHECK --interval=30s --timeout=10s --start-period=15s --retries=3 \
    CMD curl -f http://localhost:3000/login/ || exit 1

# Запуск через Gunicorn (WSGI)
CMD ["gunicorn", \
     "--bind", "0.0.0.0:3000", \
     "--workers", "2", \
     "--timeout", "60", \
     "--access-logfile", "-", \
     "--error-logfile", "-", \
     "django_project.wsgi:application"]
4.2 Развёртывание в Replit SaaS

В среде Replit TLS-терминация выполняется на уровне прокси-сервера платформы, что обеспечивает HTTPS для всех входящих соединений. Приложение запускается на порту 3000 и принимает запросы через X-Forwarded-Proto: https.

Текущий статус: Приложение работает на Replit SaaS под защитой HTTPS. Middleware HttpsRedirectMiddleware проверяет заголовок X-Forwarded-Proto и выполняет редирект при HTTP-запросах. Заголовки безопасности устанавливает SecurityHeadersMiddleware.
4.3 Проверка статуса безопасности (API)

Эндпоинт GET /api/security-status/ возвращает JSON с информацией о протоколе:

{
  "protocol": "HTTPS",
  "is_secure": true,
  "version": "2.0.0",
  "hsts_enabled": true,
  "security_headers": [
    "Strict-Transport-Security",
    "X-Content-Type-Options",
    "X-Frame-Options",
    "X-XSS-Protection",
    "Referrer-Policy",
    "Permissions-Policy",
    "Content-Security-Policy"
  ]
}

6.2 Пошаговые инструкции для ИТ-отдела Компании 1
  1. Получить Docker-образ: docker pull company2-registry/bmc_analyzer:2.0.0
  2. Остановить предыдущую версию: docker stop bmc_analyzer_v1
  3. Запустить новую версию: 
    docker run -d --name bmc_analyzer_v2 \
  -p 3000:3000 \
  -e DJANGO_SECRET_KEY="<secret>" \
  -e REPLIT_DOMAINS="yourdomain.com" \
  -v ./db.sqlite3:/app/db.sqlite3 \
  company2-registry/bmc_analyzer:2.0.0
  4. Применить миграции БД (если не запустились автоматически): docker exec bmc_analyzer_v2 python manage.py migrate
  5. Обновить конфигурацию Nginx/прокси: добавить редирект 80 → 443 и SSL-сертификат (Let's Encrypt / корпоративный CA).
  6. Выполнить smoke-тест: curl -I https://yourdomain.com/login/ → ожидается HTTP/2 200 + заголовок Strict-Transport-Security.
  7. Проверить API: curl https://yourdomain.com/api/security-status/ → {"protocol":"HTTPS","is_secure":true}.

7.3 Шаблон Release Notes (v2.0.0)

BMC_analyzer Release Notes — версия 2.0.0 (03.05.2026)

Изменение: MR-2026-001 — переход HTTP → HTTPS

  • Все HTTP-запросы автоматически перенаправляются на HTTPS (301 Redirect).
  • Добавлены заголовки безопасности: HSTS, CSP, X-Frame-Options, X-Content-Type-Options.
  • Cookie сессии защищены (Secure, HttpOnly, SameSite=Lax).
  • Добавлен API-эндпоинт /api/security-status/ для мониторинга.
  • Добавлена страница документации /docs/.
  • Приложение упаковано в Docker-контейнер (python:3.10-slim).

Требуемые действия ИТ-отдела: Обновить конфигурацию прокси, добавить SSL-сертификат, обновить Docker-образ до v2.0.0.

Обратная совместимость: Все существующие данные БД сохраняются. Пользователи перенаправляются автоматически.
